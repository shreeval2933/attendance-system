Firebase & Environment Setup

This application includes seamless fallback simulation with real-time multi-tab sync, so you can test immediately without any keys. To connect your live Firebase project:

  1. Create a project on the Firebase Console.
  2. Enable Cloud Firestore in test mode.
  3. Open firebase-config.js and replace the firebaseConfig keys with your web app credentials.
